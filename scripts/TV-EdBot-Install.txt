Ed Bot Analysis v3.0 — установка
================================

Файл: scripts/Ed_Bot_Analysis_v2.pine
В Pine Editor первая строка после //@version=6:
  indicator("Ed Bot Analysis v3.0", shorttitle="EdBot" ...

1. TradingView → Pine Editor → новый пустой индикатор
2. Удалить всё → вставить ВЕСЬ файл
3. Сохранить → «Добавить на график»
4. Снять EdStory / старый EdBot с графика (иначе каша)
5. В заголовке настроек должно быть: Ed Bot Analysis v3.0

Что смотреть (10 секунд)
------------------------
Слева внизу таблица «Разбор Ed»:
  ДЕЙСТВИЕ = ЖДАТЬ / LONG / SHORT
  Лонг если close > цена
  Шорт если close < цена
Линии на графике — иллюстрация к таблице. Каждая подписана.
Линии НЕ уходят в бесконечность.

Галочки (каждая реально рисует слой)
------------------------------------
1. Сопр. / Подд.     — жёлтый потолок, синий пол
2. Зелёная зона      — полоса у поддержки (как нефть)
3. Клин / △          — две белые границы по lookback
4. Паттерн           — 2× вершина/дно, ГиП, 1-2-3 (если найден)
5. Fib               — 38.2 / 50 / 61.8 / 78.6 с подписями + золотая зона 50–61.8
6. SMC               — последний FVG, OB, BOS, свип — все с текстом
7. Таблица разбора   — главный ответ
8. Боксы SL/TP       — только если действие не ЖДАТЬ

Если шумно: выключи 5 и 6. Картина станет как ручной разбор нефти.
Lookback 90 — ширина клина. На 15m нефти увеличь до 120, если клин короткий.

Не финансовая рекомендация. Вход — по закрытию за уровень из таблицы.
