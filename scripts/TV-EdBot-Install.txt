Ed Bot vs Ed Story — что открывать в TradingView
================================================

В репозитории ДВА разных Pine-файла:

  Ed_Bot_Analysis_v2.pine  →  indicator("Ed Bot Analysis v2", shorttitle="EdBot")
  Ed_Story_RBR_v1.pine     →  indicator("Ed Story RBR v1", shorttitle="EdStory")  ← старый тест, НЕ Ed Bot

Если в Pine Editor в первой строке после @version видишь "Ed Story RBR" — это НЕ бот.

Как поставить Ed Bot на график:
1. TradingView → Pine Editor → «Открыть» → «Новый пустой индикатор»
2. Удали всё → вставь полностью текст из:
   D:\PROJECTS\Bybit_bot\scripts\Ed_Bot_Analysis_v2.pine
3. Сохрани как «Ed Bot Analysis v2»
4. «Добавить на график»
5. ОБЯЗАТЕЛЬНО сними галочку EdStory — на скрине оба сразу ломают картину.
6. Фиолетовые 100.43 / 100.73 на шкале = старый EdBot с plot(Fib). В новом коде plot() нет.
7. После вставки в легенде EdBot не должно быть двух цен — только параметры inputs.

Пресет «как на слайдах» (рекомендуется):
  Разметка Ed — ВКЛ
  Строгий Ed — ВКЛ  ← верхние галочки (SMC, Fib, Day H/L, Forward TP…) НЕ рисуются
  Доп. слой — ВЫКЛ
  В «Разметка Ed»: зона + тренд + фигура + метки пробой/ретest по желанию
  Триггеры — ВКЛ только если нужна подсказка в подписи «Сопр./Подд.» (без второй строки справа)

Если нужен старый движок (SMC, зоны спроса, Fib, боксы SL/TP):
  Строгий Ed — ВЫКЛ
  Доп. слой — ВКЛ
  включи нужные галочки в «Режим графика»

Что реально рисуется при «Строгий Ed» ВКЛ:
  • Значимая зона → жёлтая «Сопр.» + синяя «Подд.» (линии на всю ширину)
  • Трендовая → белая TL по двум свингам
  • Фигура → только если скан нашёл паттерн с confidence ≥ MIN pattern confidence
  • Метки пробой/ретest → только если событие на последних барах
  • BOS / ликвидность → только если включены в блоке «Разметка Ed»

В легенде: indicator("Ed Bot Analysis v2.4" ...) — иначе старый код в TV.

Блок «Разметка Ed» (v2.4) сам рисует без «Доп. слоя»:
  Fib 38.2–88.6 + красная зона 78.6–88.6
  Сходящиеся линии △ по 4 свингам
  FVG (последний за ~45 бар), BOS, ликвидность, свип
  Фигура + подпись при conf ≥ «MIN conf для фигуры» (0.56)
EdStory на том же графике — снять.

На графике: таблица справа вверху + легенда справа внизу.
Не включай EdStory на том же графике.

Debug-launch TV (для CLI): scripts\Launch-TradingView-Debug.bat
